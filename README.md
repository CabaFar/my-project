# لوحة مبيعات بنك الرياض

## كيف تفتح اللوحة؟ (بدون أي أوامر)

1. افتح الملف **`لوحة-المبيعات.html`**
2. اضغط عليه مرتين
3. يفتح في المتصفح وتقدر تضيف الطلبات مباشرة

البيانات تنحفظ تلقائياً في جهازك.

---

## ماذا تسوي داخل اللوحة؟

1. اضغط **إضافة طلب**
2. عبّي: رقم الطلب، اسم العميل، المعرض، مبلغ التمويل، العمولة
3. اختر المرحلة:
   - **04** موافقة مبدئية
   - **77** عقد جاهز
   - **118** تم التمويل
4. تقدر تنقل الطلب بين المراحل بزر **نقل إلى**

---

للمطورين فقط:

```bash
npm install
npm run dev
```
