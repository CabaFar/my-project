# نسخ احتياطي Supabase — مزامنة تلقائية بين الأجهزة

## ماذا يفعل؟

- أي إضافة / تعديل / حذف يُحفظ تلقائيًا في Supabase.
- الأجهزة الأخرى تستقبل التغيير فورًا (Realtime).
- المزامنة الحالية (ExtendsClass + GitHub) تبقى كنسخة احتياطية ثانية.

## التفعيل السريع من اللوحة

1. افتح اللوحة.
2. اضغط **تفعيل نسخ Supabase**.
3. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com/dashboard).
4. انسخ أمر SQL من النافذة وشغّله في **SQL Editor**.
5. من **Project Settings → API** انسخ `Project URL` و `anon public key`.
6. الصقهما واضغط **تفعيل النسخ الاحتياطي**.

بعدها يعمل الحفظ والمزامنة تلقائيًا على كل الأجهزة التي تستخدم نفس الإعداد.

## تفعيل على مستوى النشر (اختياري)

أضف أسرار المستودع في GitHub:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

سير عمل Pages يحقنها أثناء البناء.
