# تطبيق أندرويد — لوحة مبيعات بنك الرياض

## التثبيت السريع
1. حمّل الملف: `riyadh-sales-android.apk`
2. على الجوال: اسمح بتثبيت من مصادر غير معروفة
3. افتح الملف وثبّت التطبيق

## أو بدون APK (من المتصفح)
افتح الرابط على كروم في الأندرويد:
https://cabafar.github.io/my-project/

ثم: القائمة → **تثبيت التطبيق** / Add to Home screen

## إعادة البناء للمطورين
```bash
npm run build:android
cd android && ./gradlew assembleDebug
```
